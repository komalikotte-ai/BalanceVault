\# LedgerLine



A secure financial transaction management system designed to ensure accurate money movement, prevent duplicate transactions, enforce account-level authorization, and maintain a verifiable financial ledger.



\## Project Status



Under active development as part of the Snovasys Fresher Hiring Challenge 2026.



\## Technology Stack



\- Frontend: React, Vite, JavaScript

\- Backend: Java 21, Spring Boot

\- Security: Spring Security, JWT

\- Database: PostgreSQL

\- Database migrations: Flyway

\- Testing: JUnit 5, Mockito, Testcontainers

\- Build: Maven



\## Planned Features



1\. Role-based authentication.

2\. Account creation and management.

3\. Deposits and withdrawals.

4\. Internal money transfers.

5\. Double-entry ledger.

6\. Idempotent transaction processing.

7\. Concurrency protection.

8\. Append-only audit trail.

9\. Account-level access control.

10\. Automated security and integrity tests.
